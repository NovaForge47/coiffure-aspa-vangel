# Athens Hair Dreams

Create a stunning lead generation website for a women's hair salon in Athens Greece. Business name 'Κομμωτήριο Αθήνα'. Hero section with headline 'Το Μαλλί που Πάντα Ονειρευόσουν', online booking button, services section showing haircut, coloring, styling, keratin treatment, photo gallery section, testimonials with 5 stars, contact form, location. Elegant feminine design, rose gold and white colors. Everything in Greek. Make it look like a €2000 website
